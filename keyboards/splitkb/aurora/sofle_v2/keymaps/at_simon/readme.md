# keymap by at-simon

_This keymap is a copy of the [splitkb default keymap](https://github.com/qmk/qmk_firmware/tree/master/keyboards/splitkb/aurora/sofle_v2), with some modifications._

Using the [Liatris](https://splitkb.com/products/liatris) controller.

## Compile
```bash
qmk compile -kb splitkb/aurora/sofle_v2/rev1 -km at_simon
```
